# WUZHI Portfolio

这里是关于雾质的一切。

## 目录约定

```text
/
├─ about/                  # 个人介绍
├─ projects/               # 进行中的核心项目
│  ├─ axis-i/
│  ├─ axis-ii/
│  └─ axis-iii/
├─ works/                  # 已归档作品
│  ├─ 3d-nature/
│  ├─ 3d-city/
│  ├─ 3d-memory/
│  ├─ 3d-practice/
│  ├─ foundation-art/
│  └─ south-of-south/
└─ assets/
   ├─ styles/
   ├─ scripts/
   ├─ images/
   └─ fonts/
```

页面目录统一使用小写 kebab-case，并以 `index.html` 作为入口；静态资源按类型和作品归属分组。

新增内容时同时更新：

- `content-index.json`：供页面索引或后续搜索功能读取。
- `sitemap.xml`：供搜索引擎抓取。
